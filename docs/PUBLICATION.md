# Publication checklist

The repository is currently curated as an academic portfolio project. Before making it public:

- Confirm that all project teammates agree to share the source, maps and documentation.
- The original `package.xml` declares an MIT license. Confirm that this is the intended license for all team contributions before adding a root LICENSE file.
- Review occupancy maps and any landmark descriptions for sensitive details about classrooms or real locations.
- The supplied university assignment brief belongs to the course authors; it is **not** included as a PDF pending permission to redistribute.
- Verify YouTube links from the final team presentation before adding demos.
- Rebuild and test on compatible ROS 1 hardware/simulation before making reproducibility or performance claims.

This repository is not evidence of a tested commercial deployment.
